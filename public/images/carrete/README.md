# Carrete

Deja aquí tus fotos y aparecerán solas en la web. No hay que tocar código.

- Formatos: .jpg .jpeg .png .webp .avif
- El orden es alfabético, así que nombra los archivos 01-…, 02-…, 03-… para controlarlo
- Recomendado: lado largo de 1200-1600 px y menos de 400 KB por foto
- Si la carpeta está vacía, la sección no se renderiza

El texto alternativo se saca del nombre del archivo: `03-sevilla-atardecer.jpg`
se lee como "Sevilla atardecer". Nombra los archivos de forma descriptiva —
es lo que oirá alguien usando un lector de pantalla.
